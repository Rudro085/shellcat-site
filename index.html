Everything you do over SSH, in one place

Built for administrators and developers who look after many machines: organise them once, then reach any server — directly or through Teleport — with every tool ready.

⌘

Fast, modern terminal

xterm-256color terminals with tabs, split views, search, adjustable fonts, copy/paste and clickable links. Dead connections are detected by keepalives and can be reconnected in one click. Open PowerShell or your Linux shell in a tab next to your servers.

🗂

Organised connections

Groups, colours and tags for every server. Password, private key (from the keychain or a key file), SSH agent and Teleport authentication. Duplicate a server in one click.

📜

Script palette

Save multi-line bash, sh, Python, Perl or Node scripts and run them interactively — sudo and prompts work — on one server or many at once. Import and share script packs.

🩺

Auto diagnosis

One click collects 67 read-only probes — storage, ports, processes, Nginx, Apache, HAProxy, Docker, Supervisor, workers, logs, environment and more — into an editable JSON/Markdown report ready for an AI model.

🛡

Teleport built in

Log in with tsh (SSO, OTP, security keys), browse clusters and nodes by label, request and assume access, and open nodes with full ShellCat features — with automatic fallback to tsh ssh.

📁

Files over SFTP

Browse, upload, download, rename, chmod and delete. Tab completion in the path bar, a built-in editor with find & replace, or open files in VS Code, Notepad++ or any editor you like.

⑂

Visual Git client

A full Source Control view for repositories on your servers: stage single lines, commit, branch, merge, stash, push and pull, resolve conflicts and browse a colour-coded commit graph. Clone with your saved GitHub, GitLab or Bitbucket accounts. Nothing to install on the server.

📈

Live monitor

CPU, memory, uptime and load, top processes (with one-click SIGTERM) and listening ports, refreshed every few seconds.

⇄

Port forwarding

Local and remote tunnels bound to loopback, managed per connection and closed automatically with it.

🔍

Command palette

2,000+ built-in commands across files, system, Docker, Git, networking and more. Fill in parameters and insert commands for review — nothing runs until you press Enter.

🔐

Private by design

Connections and keys live in a local AES-256-GCM vault whose key is protected by Windows DPAPI, or by your desktop keyring on Linux. Secrets never reach the UI. Host keys are verified, and diagnosis reports redact passwords and tokens.

🎨

Make it yours

Six built-in themes — Night, Daylight, Paper, Ember, Phosphor and High Contrast — and every colour, font and terminal setting in a simple appearance file. Optional on-device semantic command search.

✨

Autocomplete as you type

The rest of a likely command appears in gray from your history on that server, the command catalogue and the files around you. → accepts it, Ctrl+→ one word. Every command is marked with its exit status.

🔑

SSH keychain

Add your private keys once — from a file, pasted, or generated as Ed25519 or RSA 4096 — and pick them in any connection. Passphrases are stored encrypted, and you can see which servers use each key.

⛶

Zen mode and split view

Press F11 for a full-screen workspace with just your tabs. Split it side by side or top and bottom, or drag a tab to the edge, to watch two servers at once.

Git on your servers, without the command line

Open a repository in Files and switch to the Git tab — ShellCat finds the repository and shows everything you would otherwise type into the git CLI:

  • Staged, unstaged, untracked and conflicted files, with side-by-side or inline diffs
  • Stage, unstage or discard a whole file, a hunk or just the lines you select
  • Commit, amend, push, pull and sync, with ahead/behind counts for your branch
  • Checkout, create, merge, rebase and delete branches; stashes, tags and remotes
  • A commit graph with branch lanes and labels — open any commit to see its changes
  • Accept current, incoming or both for each merge conflict, then continue or abort

It runs the server's own git over your existing SSH connection, so there is no agent to install and it works on old distributions too.

Review every change before you commit

Click a changed file to see exactly what changed. Select individual lines to stage only part of a file, discard a single hunk, or open the file in the editor. Merge conflicts get their own view with Accept Current, Accept Incoming and Accept Both for each block.

See the Git chapter of the user manual for every action.

Clone a repository without leaving the Git tab

Paste an HTTPS or SSH address, choose the folder on the server, and clone. Add a personal access token for GitHub, GitLab or Bitbucket once in Settings → Git, and ShellCat picks the matching account for private repositories, fetches, pulls and pushes.

  • Clone a branch or tag, only the latest commit, or with submodules
  • The commit name and email of the account are set in the new repository
  • Tokens stay encrypted in your vault and are never saved on the server

Type less with autocomplete

As you type, ShellCat suggests the rest of the command in gray: commands you ran on that server before, more than 2,000 built-in commands, and file and folder names. Press → to accept it or Ctrl+→ for one word; Tab stays your shell's own completion.

With shell integration, each command gets a green or red marker for its exit status, Ctrl+↑ and Ctrl+↓ jump between commands, and relative paths in the output become clickable.

All your SSH keys in one place

Open Keychain in the header to import a key file, paste one, or generate a new Ed25519 or RSA 4096 key. Copy the public key for authorized_keys, rename keys, and see which connections use each one before you remove it.

When you add a connection, choose From keychain and pick the key: no file paths, and the passphrase is only typed once.

Full screen when you need to focus

Press F11 or the full-screen button and the sidebar and header step aside. A compact bar keeps your tabs, the Terminal, Files, Git, Monitor and Tunnels views and the split buttons within reach.

Split the workspace to follow logs on one server while you watch another's load, and drag a tab to the side of the workspace to split with it.

Six themes, one click

Pick Night, Daylight, Paper, Ember, Phosphor or High Contrast in Settings → Appearance. Every theme meets WCAG AA contrast, and High Contrast meets AAA. Apply one as a starting point, then fine-tune any colour or font in your own appearance file.

Diagnose a server in one click

Open Monitor → Auto diagnosis and ShellCat gathers a complete, read-only snapshot of the machine:

  • System, kernel limits, memory pressure, disks, inodes and I/O
  • Listening ports, firewall rules, connections and DNS
  • Nginx/Apache/HAProxy configs and config tests, TLS expiry
  • Docker containers, restart loops, health and OOM kills
  • Supervisor programs, queue workers, PM2, systemd units and logs

Built-in checks highlight problems such as full disks, failing config tests or crash-looping containers. Copy the report for an AI model, or save it as JSON or Markdown.

Scripts you can trust to run anywhere

Write a script once — flush iptables, rotate logs, restart workers — and run it whenever you need it. ShellCat uploads it to a private temporary file, runs it in a real interactive terminal and removes it afterwards.

  • Run on several servers at the same time
  • Optional sudo and confirmation for dangerous scripts
  • Ready-made templates to start from

All your Teleport servers, with every tool

ShellCat uses your installed tsh for logins, so SSO, MFA and hardware keys work exactly as in a terminal. Then browse every cluster and node, filter by label, select many and open them together — with files, monitoring, scripts and diagnosis available.

If a node needs per-session MFA, ShellCat opens it with tsh ssh automatically.

Installation

Windows

  1. Download the installer and run it.
  2. If Windows SmartScreen shows “Windows protected your PC”, choose More info → Run anyway (the installer is not code-signed yet).
  3. Follow the wizard. Microsoft Edge WebView2 is installed automatically if it is missing.
  4. Start ShellCat from the Start menu.

Debian / Ubuntu

  1. Download the .deb package.
  2. Install it (dependencies are pulled in automatically): 
    sudo apt install ./shellcat_1.4.0_amd64.deb
  3. Start ShellCat from your application menu.
Teleport users: install the Teleport tsh client (or Teleport Connect). ShellCat finds tsh automatically; you can also set its path in the Teleport panel.
Upgrading or moving to a new PC: your connections are stored in an encrypted vault. On Windows the vault key is tied to your Windows account, so back up and restore through ShellCat on the same account. See Data, backup and security.

Get started in a minute

1 · Add a server

Click New connection, enter host, port, user and choose password, key, SSH agent or Teleport.

2 · Connect

Click it in the sidebar. Verify the host fingerprint the first time, and you're in.

3 · Use the tools

Switch between Terminal, Files, Git, Monitor and Tunnels. Press Ctrl+Shift+S for scripts, Ctrl+Shift+P for commands.
