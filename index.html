Everything you do over SSH, in one place

Built for administrators and developers who look after many machines: organise them once, then reach any server — directly or through Teleport — with every tool ready.

⌘

Fast, modern terminal

xterm-256color terminals with tabs, split views, search, adjustable fonts, copy/paste and clickable links. Dead connections are detected by keepalives and can be reconnected in one click.

🗂

Organised connections

Groups, colours and tags for every server. Password, private key (with passphrase), SSH agent and Teleport authentication. Duplicate a server in one click.

📜

Script palette

Save multi-line bash, sh, Python, Perl or Node scripts and run them interactively — sudo and prompts work — on one server or many at once. Import and share script packs.

🩺

Auto diagnosis

One click collects 67 read-only probes — storage, ports, processes, Nginx, Apache, HAProxy, Docker, Supervisor, workers, logs, environment and more — into an editable JSON/Markdown report ready for an AI model.

🛡

Teleport built in

Log in with tsh (SSO, OTP, security keys), browse clusters and nodes by label, request and assume access, and open nodes with full ShellCat features — with automatic fallback to tsh ssh.

📁

Files over SFTP

Browse, upload, download, rename, chmod and delete. Tab completion in the path bar and a built-in editor with find & replace for quick config changes.

📈

Live monitor

CPU, memory, uptime and load, top processes (with one-click SIGTERM) and listening ports, refreshed every few seconds.

⇄

Port forwarding

Local and remote tunnels bound to loopback, managed per connection and closed automatically with it.

🔍

Command palette

2,000+ built-in commands across files, system, Docker, Git, networking and more. Fill in parameters and insert commands for review — nothing runs until you press Enter.

🔐

Private by design

Connections live in a local AES-256-GCM vault whose key is protected by Windows DPAPI. Secrets never reach the UI. Host keys are verified, and diagnosis reports redact passwords and tokens.

💻

Local terminal

Open PowerShell or your Linux shell in a tab next to your servers.

🎨

Make it yours

Every colour, font and terminal setting lives in a simple appearance file. Optional on-device semantic command search.

Diagnose a server in one click

Open Monitor → Auto diagnosis and ShellCat gathers a complete, read-only snapshot of the machine:

  • System, kernel limits, memory pressure, disks, inodes and I/O
  • Listening ports, firewall rules, connections and DNS
  • Nginx/Apache/HAProxy configs and config tests, TLS expiry
  • Docker containers, restart loops, health and OOM kills
  • Supervisor programs, queue workers, PM2, systemd units and logs

Built-in checks highlight problems such as full disks, failing config tests or crash-looping containers. Copy the report for an AI model, or save it as JSON or Markdown.

Scripts you can trust to run anywhere

Write a script once — flush iptables, rotate logs, restart workers — and run it whenever you need it. ShellCat uploads it to a private temporary file, runs it in a real interactive terminal and removes it afterwards.

  • Run on several servers at the same time
  • Optional sudo and confirmation for dangerous scripts
  • Ready-made templates to start from

All your Teleport servers, with every tool

ShellCat uses your installed tsh for logins, so SSO, MFA and hardware keys work exactly as in a terminal. Then browse every cluster and node, filter by label, select many and open them together — with files, monitoring, scripts and diagnosis available.

If a node needs per-session MFA, ShellCat opens it with tsh ssh automatically.

Installation

Windows

  1. Download the installer and run it.
  2. If Windows SmartScreen shows “Windows protected your PC”, choose More info → Run anyway (the installer is not code-signed yet).
  3. Follow the wizard. Microsoft Edge WebView2 is installed automatically if it is missing.
  4. Start ShellCat from the Start menu.

Portable: put ShellCat-go.exe anywhere and run it (requires WebView2, which is preinstalled on Windows 11).

Debian / Ubuntu

  1. Download the .deb package.
  2. Install it (dependencies are pulled in automatically):
    sudo apt install ./shellcat_amd64.deb
  3. Start ShellCat from your application menu.

Other Linux (portable)

  1. Install the runtime libraries:
    # Ubuntu 24.04+ / Debian 13
sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
# Ubuntu 22.04 / Debian 12
sudo apt install libgtk-3-0 libwebkit2gtk-4.0-37
# Fedora
sudo dnf install gtk3 webkit2gtk4.1
# Arch
sudo pacman -S gtk3 webkit2gtk-4.1
  2. Extract and run:
    tar xzf ShellCat-go-linux-amd64.tar.gz
./ShellCat-go
Teleport users: install the Teleport tsh client (or Teleport Connect). ShellCat finds tsh automatically; you can also set its path in the Teleport panel.
Upgrading or moving to a new PC: your connections are stored in an encrypted vault. On Windows the vault key is tied to your Windows account, so back up and restore through ShellCat on the same account. See Data, backup and security.

Get started in a minute

1 · Add a server

Click New connection, enter host, port, user and choose password, key, SSH agent or Teleport.

2 · Connect

Click it in the sidebar. Verify the host fingerprint the first time, and you're in.

3 · Use the tools

Switch between Terminal, Files, Monitor and Tunnels. Press Ctrl+Shift+S for scripts, Ctrl+Shift+P for commands.
